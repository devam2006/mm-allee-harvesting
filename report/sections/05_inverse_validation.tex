\section{Inverse PINNs, Identifiability, and Held-Out Validation}
\label{sec:inverse_validation}

\subsection{Problem Formulation and Structural Identifiability}
Inverse parameter estimation for harvesting models seeks to infer unknown biophysical parameters $\mathbf{p} = (r, K, A, H \text{ or } h)$ from noisy discrete population observations $y_i \approx N(t_i)$. Before applying numerical optimization or machine learning techniques, we must analyze the \emph{structural identifiability} of each governing equation: whether distinct parameter sets can produce mathematically identical observation trajectories in the noise-free limit.

\subsubsection{Model B: Polynomial Expansion and Structural Nonidentifiability}
Under Model B, harvesting is proportional to population density (constant effort $h$). The dimensional dynamical equation is:
\begin{equation}
\frac{\mathrm{d}N}{\mathrm{d}t} = r N \left(1 - \frac{N}{K}\right)\left(\frac{N}{A} - 1\right) - h N.
\label{eq:model_b_ode}
\end{equation}
Expanding the cubic polynomial on the right-hand side yields:
\begin{align}
\frac{\mathrm{d}N}{\mathrm{d}t} &= r N \left(\frac{N}{A} - 1 - \frac{N^2}{A K} + \frac{N}{K}\right) - h N \nonumber \\
&= -(r + h) N + r \left(\frac{1}{A} + \frac{1}{K}\right) N^2 - \frac{r}{A K} N^3.
\label{eq:model_b_expansion}
\end{align}
Equation~\eqref{eq:model_b_expansion} reveals that continuous population observations under a single unknown constant effort $h$ depend strictly on three composite polynomial coefficients:
\begin{equation}
c_1 = -(r + h), \quad c_2 = r \left(\frac{1}{A} + \frac{1}{K}\right) = \frac{r(A+K)}{AK}, \quad c_3 = -\frac{r}{AK}.
\label{eq:model_b_coefficients}
\end{equation}
Because the physical vector field is entirely specified by the triplet $(c_1, c_2, c_3)$, an inverse problem attempting to infer the four distinct parameters $(r, A, K, h)$ from observations at a single fixed effort is \textbf{structurally nonidentifiable}: three independent equations cannot uniquely determine four unknowns.

\paragraph{Explicit Counterexample.}
Consider the two distinct parameter sets declared in the scientific contract:
\begin{align}
\mathbf{p}_1 &= (r_1, A_1, K_1, h_1) = (1.0, 0.2, 1.0, 0.5), \label{eq:set1} \\
\mathbf{p}_2 &= (r_2, A_2, K_2, h_2) = (1.35, 0.3, 0.9, 0.15). \label{eq:set2}
\end{align}
Evaluating the composite coefficients for each set:
\begin{align*}
\text{For } \mathbf{p}_1: \quad &c_1 = -(1.0 + 0.5) = -1.5, \\
&c_2 = 1.0 \left(\frac{1}{0.2} + \frac{1}{1.0}\right) = 6.0, \\
&c_3 = -\frac{1.0}{0.2 \times 1.0} = -5.0. \\
\text{For } \mathbf{p}_2: \quad &c_1 = -(1.35 + 0.15) = -1.5, \\
&c_2 = 1.35 \left(\frac{1}{0.3} + \frac{1}{0.9}\right) = 1.35 \times \frac{4}{0.9} = 6.0, \\
&c_3 = -\frac{1.35}{0.3 \times 0.9} = -\frac{1.35}{0.27} = -5.0.
\end{align*}
Both parameter sets produce the exact same cubic vector field:
\begin{equation}
\frac{\mathrm{d}N}{\mathrm{d}t} = -1.5 N + 6.0 N^2 - 5.0 N^3.
\end{equation}
Consequently, for any given initial state $N(0) = N_0$, the solution trajectory $N(t)$ generated by $\mathbf{p}_1$ and $\mathbf{p}_2$ is mathematically identical for all $t \ge 0$. 

\paragraph{Insufficiency of Multiple Initial Conditions.}
A common misconception is that observing multiple trajectories from different initial populations $N_0^{(1)}, N_0^{(2)}, \dots$ at the same effort $h$ can break this nonidentifiability. However, because every such trajectory satisfies the identical differential equation $\dot{N} = c_1 N + c_2 N^2 + c_3 N^3$, varying the initial condition only generates different integral curves of the \emph{same} three coefficients. It adds zero independent constraints on the underlying four parameters. To identify $(r, A, K, h)$, one must either:
\begin{enumerate}
    \item Independently determine carrying capacity $K$ (or intrinsic rate $r$) from unharvested surveys, reducing the system to three unknowns $(r, A, h)$; or
    \item Conduct experiments with multiple known effort levels $h^{(1)} \ne h^{(2)}$, allowing separation of $r$ from $h$ via $c_1(h^{(1)}) - c_1(h^{(2)}) = -(h^{(1)} - h^{(2)})$.
\end{enumerate}

\subsubsection{Model A: Structural Identifiability and Practical Conditioning}
Under Model A (constant yield harvesting $H$), the differential equation is:
\begin{equation}
\frac{\mathrm{d}N}{\mathrm{d}t} = -H - r N + r \left(\frac{1}{A} + \frac{1}{K}\right) N^2 - \frac{r}{A K} N^3.
\label{eq:model_a_expansion}
\end{equation}
Here, four independent polynomial coefficients appear:
\begin{equation}
c_0 = -H, \quad c_1 = -r, \quad c_2 = r\left(\frac{1}{A} + \frac{1}{K}\right), \quad c_3 = -\frac{r}{AK}.
\end{equation}
From these, we directly identify:
\begin{equation}
H = -c_0, \quad r = -c_1, \quad P = AK = -\frac{r}{c_3}, \quad S = A + K = -\frac{c_2}{c_3}.
\end{equation}
The values of $A$ and $K$ are the roots of the quadratic equation $z^2 - S z + P = 0$. Since the ecological domain imposes the strict physical ordering $0 < A < K$, the root permutation ambiguity is uniquely broken: $A = (S - \sqrt{S^2 - 4P})/2$ and $K = (S + \sqrt{S^2 - 4P})/2$. 

Thus, Model A is \textbf{structurally identifiable} from ideal data. However, in \emph{practical} scenarios with finite, noisy measurements collected near equilibrium where $\mathrm{d}N/\mathrm{d}t \approx 0$, higher-order polynomial coefficients become severely ill-conditioned. A tiny perturbation in observation noise causes large deviations in estimated $A$ and $K$. Therefore, our main experimental design fixes known carrying capacity $K=100.0$ and focuses on estimating the identifiable subset $(r, A, H)$ for Model A and $(r, A, h)$ for Model B.

\subsection{Inverse Physics-Informed Neural Network (PINN) Engine}
We design a unified JAX Physics-Informed Neural Network architecture and trainer sharing the foundational autodiff and network primitives of WP04.

\subsubsection{Network Architecture and Hard Initial Conditions}
Following the WP04 foundation, the network enforces initial conditions strictly by construction:
\begin{equation}
x(t) = x_0 + \frac{t}{t_{\mathrm{end}}} \mathcal{N}_\theta\left(\frac{t}{t_{\mathrm{end}}}\right) \implies x(0) \equiv x_0,
\end{equation}
where $x_0 = N_0 / K \in [0, 1.5]$ and $\mathcal{N}_\theta$ is a Multi-Layer Perceptron ($[32, 32]$ hidden units with $\tanh$ activation). Dimensional predictions are given by $N_\theta(t) = K \cdot x(t)$. Time derivatives $\mathrm{d}x/\mathrm{d}t$ are computed via JAX exact reverse-mode automatic differentiation ($\mathrm{vmap}(\mathrm{grad})$), guaranteeing machine-precision kinematics without finite-difference approximations.

\subsubsection{Constraint-Preserving Parameter Parameterization}
Physical parameters must satisfy strict ecological bounds: $r > 0$, $0 < A < K$, $H \ge 0$, and $h \ge 0$. Imposing artificial box penalties or hard clamping detaches autodiff gradients ($\nabla = 0$) when boundaries are reached. To guarantee continuous, nonzero gradients across the entire optimization trajectory, we construct smooth bijective transformations:
\begin{align}
r &= \mathrm{softplus}(\tilde{r}) = \ln(1 + e^{\tilde{r}}) > 0, \label{eq:r_transform} \\
A &= K \cdot \sigma(\tilde{A}) = K \cdot \frac{1}{1 + e^{-\tilde{A}}} \in (0, K) \implies a = \frac{A}{K} \in (0, 1), \label{eq:A_transform} \\
H &= \mathrm{softplus}(\tilde{H}) \ge 0, \quad h = \mathrm{softplus}(\tilde{h}) \ge 0, \label{eq:harvest_transform}
\end{align}
where $\tilde{r}, \tilde{A}, \tilde{H}, \tilde{h} \in \mathbb{R}$ are unconstrained latent parameters. The derivatives $\mathrm{d}r/\mathrm{d}\tilde{r} = \sigma(\tilde{r}) > 0$ and $\mathrm{d}A/\mathrm{d}\tilde{A} = K \sigma(\tilde{A})(1 - \sigma(\tilde{A})) > 0$ are strictly positive for all finite values, ensuring gradient backpropagation never stalls.

\subsubsection{Loss Function and Leakage-Protected Optimization}
The total objective function combines data fidelity on training points and physical ODE residuals across the collocation horizon:
\begin{equation}
\mathcal{L}(\theta, \tilde{\mathbf{p}}) = \lambda_{\mathrm{data}} \mathcal{L}_{\mathrm{data}} + \lambda_{\mathrm{phys}} \mathcal{L}_{\mathrm{phys}}.
\label{eq:total_loss}
\end{equation}
\begin{enumerate}
    \item \textbf{Data Loss ($\mathcal{L}_{\mathrm{data}}$):} Evaluated strictly on training observations $\mathcal{D}_{\mathrm{train}}$:
    \begin{equation}
    \mathcal{L}_{\mathrm{data}} = \frac{1}{|\mathcal{D}_{\mathrm{train}}|} \sum_{i \in \mathcal{D}_{\mathrm{train}}} \left(x_\theta(t_i) - \frac{y_i}{K}\right)^2.
    \end{equation}
    \item \textbf{Physics Residual Loss ($\mathcal{L}_{\mathrm{phys}}$):} Collocation points $t_j \in [0, t_{\mathrm{end}}]$ enforce the governing differential equation using JAX automatic differentiation:
    \begin{equation}
    \mathcal{R}(t_j) = \frac{\mathrm{d}x_\theta}{\mathrm{d}t}\bigg|_{t_j} - f_{\mathrm{norm}}(x_\theta(t_j); \mathbf{p}), \quad \mathcal{L}_{\mathrm{phys}} = \frac{1}{M} \sum_{j=1}^M \left(\mathcal{R}(t_j)\right)^2.
    \end{equation}
\end{enumerate}
Validation observations $\mathcal{D}_{\mathrm{val}}$ never enter the gradient. The trainer can use them for early stopping and checkpoint selection (option \texttt{validation\_selection}); the adopted setting switches this \emph{off}, for the reason given in Section~\ref{sec:inverse_convergence} (on a flat late-time window it can return an early, barely trained state), so in the final experiments the validation points are only reported. Test observations $\mathcal{D}_{\mathrm{test}}$ remain completely frozen and unseen throughout training.

\subsubsection{Two-Phase Optimizer (Adam $\to$ L-BFGS) and the shared setting}
Training combines Phase~1 (Adam, 1000 iterations) with separate learning rates for the network weights ($\eta_{\mathrm{net}} = 10^{-3}$) and for the latent physical parameters ($\eta_{\mathrm{params}} = 10^{-3}$) to move into a favourable basin, followed by Phase~2 (L-BFGS-B via \texttt{scipy.optimize.minimize}, 2500 iterations, with the tolerance-based stop switched off so that the full iteration budget is used). The loss weights are $\lambda_{\mathrm{data}}=1$ and $\lambda_{\mathrm{phys}}=0.1$, with 300 collocation points on $[0,t_{\mathrm{end}}]$ and validation selection off. The network (two hidden layers of 32 units, $\tanh$), the network learning rate, the number of collocation points and the Adam/L-BFGS budget are \emph{identical} to those of the forward problem (Section~\ref{sec:forward_pinn}), where the choice of this shared setting is documented; $\lambda_{\mathrm{phys}}$, $\eta_{\mathrm{params}}$ and the validation option exist only in the inverse problem.

\subsection{Conventional ODE Least-Squares Baseline}
As an independent, rigorous benchmark, we implement a conventional nonlinear least-squares ODE solver using SciPy (\texttt{scipy.optimize.least\_squares} with the Trust Region Reflective algorithm). The forward trajectory is numerically integrated using adaptive Runge-Kutta Dormand-Prince (RK45) methods. The objective function minimizes normalized observation residuals on the identical training split:
\begin{equation}
\min_{\mathbf{p}} \frac{1}{2} \sum_{i \in \mathcal{D}_{\mathrm{train}}} \left(\frac{N_{\mathrm{sim}}(t_i; \mathbf{p}) - y_i}{N_{\mathrm{ref}}}\right)^2,
\end{equation}
subject to the exact same physical parameter bounds: $r \in [10^{-4}, 10]$, $A \in [10^{-4}, K]$, and $H, h \ge 0$.

\subsection{Experimental Design and Results}
\label{sec:inverse_design}
Experiments use the six synthetic reference trajectories of the WP03 fixture: Model~A regular, near-fold and extinction, and Model~B regular, near-fold and decline, generated with known true parameters $r=0.7$, $K=100.0$, $A=20.0$, Model~A harvest $H \in \{10.0, 36.5, 70.0\}$ and Model~B effort $h \in \{0.21, 0.5544\}$. Each trajectory has \textbf{101 observations} on $t \in [0,8]$ (spacing $0.08$), split into contiguous windows: \textbf{61 training points} ($0 \le t \le 4.80$), \textbf{20 validation points} ($4.88 \le t \le 6.40$) and \textbf{20 held-out test points} ($6.48 \le t \le 8.00$). Additive Gaussian noise of standard deviation $\sigma N_{\mathrm{ref}}$ with $N_{\mathrm{ref}}=100$ and $\sigma \in \{0, 0.01, 0.05\}$ is added; the noise seed is the run seed and the network seed is $1000+$ the run seed, with seeds $\{11, 22, 33\}$. The carrying capacity $K$ and the initial population are known and $(r, A, H\text{ or }h)$ are fitted. The initial population $N_0$ (45, 85, 80 and 10 for the four distinct starting states) is treated as independently known and \emph{exact}: it is the noise-free value even in the $\sigma=0.01$ and $\sigma=0.05$ runs, the PINN's hard initial condition uses it, and the ODE fit starts from it, so both methods have a noise-free anchor at $t=0$. All errors are relative errors per parameter, given in scientific notation. The training data enter the loss only through the 61 training points, and the physics residual is enforced at 300 collocation points over the full window $[0,8]$. The status \texttt{converged} only says that the Adam phase finished and a finite solution was returned; how L-BFGS ended is reported separately (column \texttt{lbfgs\_outcome} of the prediction table). In all 54 fits L-BFGS stopped at its 2500-iteration limit, with no optimiser error or abnormal exit and no tolerance reached (the tolerance stop is switched off), so convergence is judged by the training error relative to the noise level: for the 36 noisy fits it lies between $0.65$ and $1.15$ times the noise standard deviation (median $0.87$).

\subsubsection{Why the original settings failed}
The settings used for the first complete sweep (two hidden layers of 64, 120 collocation points, 1500 Adam epochs with validation early stopping and 200 L-BFGS iterations that stop on tolerances) recovered \textbf{none of the 18 clean fits}, and all 54 fits ended with the status \texttt{validation\_\allowbreak{}stopped}, while the conventional ODE baseline recovered all 18. The main cause is the optimiser budget: with 2500 L-BFGS iterations and no tolerance stop the same trainer recovers the well-conditioned cases to $10^{-3}$--$10^{-5}$. We therefore kept the original runs only as provenance, in the files \texttt{artifacts/\allowbreak{}tables/\allowbreak{}wp05\_\allowbreak{}*\_\allowbreak{}original\_\allowbreak{}settings.csv} and repeated the whole sweep with the shared setting.

\subsubsection{Convergence and the Role of Noise}
\label{sec:inverse_convergence}
To test whether the synthetic noise explains the fits that do not converge, we repeated the study at $\sigma \in \{0, 0.001, 0.005, 0.01\}$ with tanh and swish (144 fits, seeds 11, 22, 33), judging convergence and recovery separately. \emph{Optimiser convergence} is the ratio of the training RMSE to the noise standard deviation, which is about $0.9$ for a correct fit. \emph{Recovery} is the error relative to the Cramér--Rao bound.
\begin{itemize}
    \item \textbf{Noise does not stop the optimiser.} With the trainer's default validation-based checkpoint selection, 132 of 144 fits reach the noise floor and none overfits; the errors of the well-conditioned cases grow in proportion to $\sigma$ at about $1.3$--$1.4$ times the bound; and the share of collapsed fits does not depend on $\sigma$ (6 of 36 at $\sigma=0$ and 9, 9, 7 of 36 at the three noisy levels).
    \item \textbf{The 12 fits that missed the noise floor had a common cause.} All but one ended \texttt{validation\_\allowbreak{}stopped} with their parameters still at the starting guess (worst-parameter error exactly $0.5$). The trainer restores the ``best validation'' checkpoint and rejects an L-BFGS result whose validation loss is more than 5\% worse; on a flat late-time validation window an early, barely trained state can win that comparison.
    \item \textbf{With validation selection switched off, all 144 fits reach the noise floor}, but parameter recovery does not improve overall (for tanh, the number of the 18 fits within $5\times10^{-2}$ at the four noise levels $0$, $0.001$, $0.005$ and $0.01$ is 8, 8, 2, 1 with selection and 10, 7, 2, 1 without). The fits that used to stay at their starting guess now converge into the degenerate valley and can land further from the truth, which reflects the poor conditioning of those cases rather than a training failure.
\end{itemize}
Tanh was at least as good as swish at every noise level. The noise study used 3 seeds per cell, so small differences between the two activations are not conclusive.

\subsubsection{Difficult Regimes and Failure Analysis}
\begin{itemize}
    \item \textbf{Poor conditioning.} Model~A near-fold, Model~B near-fold and Model~B decline have condition numbers of $10^{3}$ to $2\times10^{4}$, and Model~A extinction $3.4\times10^{2}$ (Table~\ref{tab:clean_recovery}). Poor conditioning makes recovery sensitive to fitting error. With the adopted setting on clean data, Model~B near-fold recovered in all three runs (worst-parameter relative error $3.9\times10^{-4}$ to $2.5\times10^{-3}$), whereas Model~A near-fold recovered in none (parameters off by about $100\%$), Model~B decline in none (worst-parameter error $0.19$ to $0.32$) and Model~A extinction in one of three ($0.04$ to $0.26$). In the failed cases the PINN fits the training data almost perfectly (relative training error $10^{-4}$ to $10^{-5}$); a data fit of that accuracy is not tight enough for these conditioning numbers, while the ODE fit reaches $10^{-7}$ to $10^{-10}$. None of the other settings tested (more L-BFGS iterations, other loss weights and parameter learning rates, other activations and widths) fixed Model~A near-fold or Model~B decline on the seeds tried. Those cases were therefore not reliably recovered by the tested PINN settings and budgets; this is \emph{not} the proven structural ambiguity of Model~B with all four parameters unknown, because here $K$ is known and the ODE fit recovers every case.
    \item \textbf{The degenerate valley.} In the Model~A near-fold fits $r$ and $A$ both collapse to about $10^{-8}$--$10^{-4}$ ($r$ from $0.7$, $A$ from $20$) while their ratio $r/A$ stays fixed, which preserves the cubic production term, so the data can still be fitted by a reduced model. The softplus transform allows the optimiser to slide down this valley without penalty; a remedy would need parameter bounds or a different parametrisation, not a hyperparameter.
    \item \textbf{ODE baseline limits.} A candidate parameter set whose simulated trajectory goes extinct before the last observation is padded with zero population after the extinction time, which is the harvest-shutdown convention applied to the observation model. The conventional baseline converged in 52 of 54 runs; in two Model~A near-fold runs at $\sigma=0.01$ (seeds 11 and 33) it reached the maximum evaluation budget (\texttt{failed: maximum number of function evaluations}).
    \item \textbf{Held-out window.} With the shared setting the PINN predicts the held-out window ($t > 6.4$) of the regular cases accurately (Figure~\ref{fig:wp05_heldout_failure}); the median test error against the clean reference is $1.6\times10^{-4}$ at $\sigma=0$, $3.8\times10^{-3}$ at $\sigma=0.01$ and $4.9\times10^{-2}$ at $\sigma=0.05$ (original settings: $1.1\times10^{-1}$, $1.0\times10^{-1}$, $1.4\times10^{-1}$, relative $L^2$). The regular trajectories are already at equilibrium by $t=4.8$, so this window is an undemanding, physics-supported prediction test: the collocation points cover the whole interval $[0,8]$, including the held-out window, so it is not extrapolation outside the physics domain, and we do not claim the PINN extrapolates dynamics beyond the data.
\end{itemize}

\subsection{Summary and Methodological Lessons}
This investigation establishes the following findings:
\begin{enumerate}
    \item Structural nonidentifiability is an intrinsic property of Model~B with unknown effort that cannot be overcome by data volume or initial state diversity;
    \item Constrained parameter transformations via softplus and sigmoid guarantee non-negative, ordered parameters while preserving autodiff gradient signals, but they allow $r$ and $A$ to collapse together along a degenerate valley;
    \item Classical nonlinear ODE regression is orders of magnitude faster and more parameter-accurate on scalar ODEs than PINNs, and recovers all six cases on clean data, so it is an indispensable benchmark;
    \item Trajectory fit does not guarantee parameter recovery: the PINN fits every case to about $10^{-4}$ or better but recovers the parameters only where the problem is well conditioned (10 of 18 clean fits), and under noise only as well as the Cramér--Rao bound allows;
    \item Optimiser settings can silently produce unconverged results: a short L-BFGS budget with a tolerance stop and validation-based checkpoint selection returned near-initial parameters in every run of the original sweep; comparing the training error with the noise level exposes this, and a held-out validation score alone does not;
    \item Rigorous data leakage prevention (training-only observations in the loss, a frozen held-out test window) remains essential, and results must be judged against what any estimator could achieve (the Cramér--Rao bound), not against zero error.
\end{enumerate}
