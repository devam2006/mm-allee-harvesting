\section{Forward PINNs: solving the equation with a neural network}
\label{sec:wp04}

\paragraph{Question.} If a small neural network is given only the differential equation and the starting population, how well can it predict the population over time, compared with a standard numerical solver? All data in this section are synthetic and scaled ($x=N/K$, $\tau=rt$). The time interval is $\tau\in[0,T]$ with $T=10$ (for a Model A run that goes extinct, $T$ is the extinction time) and $x\in[0,1]$. The setting described here is the \emph{same} one used later for the inverse problem (Section~\ref{sec:wp05}).

\subsection{The idea}
A physics-informed neural network (PINN) \cite{raissi2019physics} is a neural network $\hat x(\tau)$ that is trained to satisfy a differential equation rather than to match measured data. We write both models as $\dot x=f(x)$, with $f(x)=G(x)-q$ for Model A and $f(x)=G(x)-ex$ for Model B. For any candidate $\hat x$, the \emph{residual}
\begin{equation}
R(\tau)=\frac{d\hat x}{d\tau}-f(\hat x)
\end{equation}
measures how badly the equation is violated at time $\tau$. If $R\equiv0$ and the starting value is right, $\hat x$ is the solution. Training therefore means making $R$ small at many chosen times, called \emph{collocation points}. The derivative $d\hat x/d\tau$ is obtained exactly by automatic differentiation, so no finite-difference step is involved. No solver solution is ever used as a training label.

\subsection{Building the starting condition into the network}
A fully connected network $N(s;\theta)$ with layer sizes $(1,32,32,1)$ and the $\tanh$ activation is evaluated at the rescaled time $s=\tau/T\in[0,1]$. We define
\begin{equation}
\hat x(\tau)=x_0+s\,N(s;\theta),
\end{equation}
so that $\hat x(0)=x_0$ \emph{exactly, for any weights} \cite{lagaris1998artificial}. No separate penalty for the starting value is needed, and the optimiser can spend all its effort on the equation. By the chain rule and the product rule, $d\hat x/d\tau=T^{-1}\bigl(N+s\,\partial_sN\bigr)$. The code uses the JAX library \cite{jax2018github} in 64-bit arithmetic.

\subsection{Loss and training}
The loss is the mean squared residual over $n=300$ fixed, uniformly spaced collocation times $\tau_i\in[0,T]$:
\begin{equation}
\mathcal L(\theta)=\frac1n\sum_{i=1}^{n}R(\tau_i)^2 .
\end{equation}
For Model A with extinction, the training interval ends at the extinction time, so the zero tail never enters the residual. Training has two phases that are common practice for PINNs. First the Adam optimiser \cite{kingma2015adam} runs for 1000 iterations at learning rate $10^{-3}$ to reach a good region of weight space (about $2/7$ of the 3500-iteration budget). Then L-BFGS \cite{liu1989limited}, a method that uses curvature information, runs for 2500 iterations with its tolerance-based stop switched off, so that it always uses the full budget and is not ended early by a loose stopping rule.

\subsection{How the answer is scored}
The reference is a dense DOP853 solution (relative tolerance $10^{-12}$) \cite{hairer1993solving}, kept separate from training. We report the root-mean-square error (RMSE), the mean absolute error, the \emph{relative $L^2$ error} (the size of the error relative to the size of the solution), the largest error, and the largest error where $x_{\rm ref}<0.05$ (the near-zero error, since a small absolute error can still be a large relative one there). A prediction containing NaN or infinity is never scored and is labelled invalid, and a run that raises an exception is recorded as failed. A run is \emph{inaccurate} if its relative $L^2$ error exceeds $5\times10^{-2}$; this threshold was fixed beforehand.

\subsection{Choosing the setting}
\label{sec:selection}
The network setting was chosen by trial and error. We trained the forward PINN with three activation functions (tanh, swish \cite{ramachandran2017searching} and sigmoid) at different learning rates, using the same fixed seeds (0, 1 and 42) and the same six test cases for every candidate. The combination of activation function and learning rate that gave the most accurate solutions was adopted: tanh with a network learning rate of $10^{-3}$, together with the other choices described above (a $(1,32,32,1)$ network, 300 collocation points and the Adam then L-BFGS schedule). This single setting is used for all the results below and, unchanged, for the inverse problem in Section~\ref{sec:wp05}.

Because the setting was selected on seeds 0, 1 and 42, accuracy on those seeds is optimistic. To check that the network really learns the model, and not just those particular runs, we repeated the whole experiment with the frozen setting on three further seeds (11, 22 and 33) that played no part in the selection.


\subsection{Results}
\label{sec:forward_results}
Table~\ref{tab:forward_results} gives the final run with the frozen setting (tanh, $(1,32,32,1)$, learning rate $10^{-3}$, 300 points, seeds 0, 1, 42). All 18 runs are accurate. The relative $L^2$ error ranges from $2.9\times10^{-7}$ to $4.1\times10^{-3}$, with a median of $6.4\times10^{-6}$. The hardest case is Model A near the fold, where the population lingers near the old steady state before collapsing (Section~\ref{sec:wp03}). On the three fresh seeds (11, 22, 33), which played no part in the selection, all 18 runs were again accurate (errors $1.4\times10^{-7}$ to $2.3\times10^{-3}$, median $5.8\times10^{-6}$), so 36 of 36 runs are accurate in all.

Some further observations:
\begin{itemize}
\item \textbf{Negative values.} Five of the 18 runs predict slightly negative populations near zero: Model B decay for seeds 1 and 42 (23 and 61 of 1001 sample points) and one sample each for Model A extinction (two runs) and Model A near-fold (one run). The near-zero error (the largest absolute error where $x_{\rm ref}<0.05$) is $8.9\times10^{-8}$ to $1.9\times10^{-7}$ for Model A extinction, $7.3\times10^{-7}$ to $2.6\times10^{-6}$ for Model B decay and $4.8\times10^{-6}$ to $8.6\times10^{-3}$ for Model A near-fold.
\item \textbf{The iteration budget is binding.} In every run L-BFGS stopped at its 2500-iteration limit, not through an abnormal exit; longer runs were not tried.
\item \textbf{Speed.} The classical RK45 solver matches the reference to between $6\times10^{-11}$ and $1.4\times10^{-9}$ in 4 to 10 milliseconds. Each PINN run took 3.2 to 4.6 seconds. For a single scalar equation the classical solver is clearly the better tool; the value of the PINN lies in being the engine for the inverse problem (Section~\ref{sec:wp05}).
\item \textbf{Extinction time is not predicted.} For Model A the horizon $T$ is the extinction time taken from the reference solver. The forward PINN does \emph{not} predict the extinction time itself.
\end{itemize}

\subsection{Limits}
There is one parameter set per regime, three seeds per set, and one computer; individual results depend on the platform and library versions, which are recorded in the run manifests. The setting was selected on one set of seeds and confirmed on another. Most importantly, a small training loss is not by itself evidence of accuracy: the early failures had small loss at the collocation points and large error between them. The reference comparison, not the loss, is what establishes accuracy.
