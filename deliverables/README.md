# Final notebook and EPS figures

[**Download the final ZIP**](https://github.com/devam2006/mm-allee-notebook-runtime/releases/download/notebook-eps-v4/mm-allee-final-notebook-eps.zip).

`mm-allee-final-notebook-eps.zip` contains exactly **20 files**: Devam's finalized `project.ipynb` and all **19 EPS figures** under `figures/`. There is no report draft, PDF, PNG export, source/data folder or extra manifest inside this ZIP. The checksum inventory is stored separately in `mm-allee-final-notebook-eps.manifest.json`. Rebuild with `python scripts/package_notebook_eps.py`.
