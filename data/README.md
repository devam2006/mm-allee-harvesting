# Synthetic data: start here

No external population dataset is used. All trajectories solve the declared mathematical models; noise is generated with recorded seeds.

| Location | Contents and use |
|---|---|
| [`fixtures/wp03_reference/`](fixtures/wp03_reference/) | Six clean CSV trajectories, 101 samples each (606 total): `a_regular`, `a_near_fold`, `a_extinction`, `b_regular`, `b_near_fold`, `b_decline`. |
| [`conditions.json`](fixtures/wp03_reference/conditions.json) | Independently declared known initial conditions and external scales. |
| [`truth.json`](fixtures/wp03_reference/truth.json) | Evaluation-only true parameters; do not pass hidden unknown truth to fitting. |
| [`manifest.json`](fixtures/wp03_reference/manifest.json) and [`validation.csv`](fixtures/wp03_reference/validation.csv) | Solver settings, provenance, checksums and independent validation. |
| [Public noisy-observation CSV](https://github.com/devam2006/mm-allee-notebook-runtime/blob/main/datasets/wp05_observations.csv) | Reconstructed frozen-config noisy observations, noise/split labels and 54 scenarios; see the companion's dataset README. These are reproducible reconstructions, not claimed byte-identical to unsaved historical arrays. |
| [`../artifacts/tables/`](../artifacts/tables/) | Recorded errors, inferred parameters and prediction metrics; these are result tables rather than training datasets. |

Regenerate the six clean trajectories with `python experiments/wp03/generate_reference.py --config configs/wp03_reference.json --output results/wp03-reference`. The final inverse design is in [`configs/wp05_final.json`](../configs/wp05_final.json); noise/splits are generated by `src/mm_allee/data.py` and the inverse experiment runner. Use `(dataset_id, observation_id)` to identify observations and fit only training observations. Keep clean evaluation truth and held-out values separate from fitting.

The [reproduction guide](../docs/REPRODUCIBILITY.md) explains each source/figure/table. [`docs/DATA_PROVENANCE.md`](../docs/DATA_PROVENANCE.md) retains detailed provenance. `raw/` and `generated/` are development locations; bulk generated results are ignored, while the small reference fixtures and manifests are versioned.
